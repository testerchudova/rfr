# ДЗ №03: результат и проверки

База PR — `v3/l03-junit-live` (`10be86b0`), рабочая ветка — `hw/03-junit-live`.

Добавлено предусловие `@User(outcomeInvitations = …)` и отдельный декоратор исходящих приглашений: requester — основной пользователь, статус — PENDING. SingleUserFixture и существующие декораторы не менялись; в UserExtension изменена только строка создания UserRequest.

Три TabTest проверяют собственные связи, отсутствие чужих связей, кнопки и пустые вкладки. Кнопки Remove, Accept, Decline и Cancel не нажимаются. В содержательных сценариях по одному связанному пользователю у каждого из двух независимых владельцев; в пустых — один владелец без связей и один с чужой связью. Роли и доступные имена проверены через Playwright MCP на ширине 1920 px. Ожидание ответа GraphQL при открытии People/вкладки предшествует проверке пустоты, чтобы начальное состояние загрузки не считалось результатом.

StaticUserFixture арендует пользователя из одной JVM-очереди на три элемента; ожидание ограничено двумя секундами, close возвращает только свою аренду и не меняет БД. UsersQueueExtension регистрирует фикстуру в Store до create. Для пула достаточно учебных пар username/password, заводить их в стенде не требуется.
