# rfr-api

Подробности API и схемы — в [README.md](README.md).

- Профиль, страны, люди и дружба работают с БД `rangiffler-api`. Профиль создаётся при первом `Query.user` со страной `ru`; регистрация в auth сама по себе профиль не создаёт.
- Лента и статистика читаются из `src/main/resources/mock/*.json`. Создание, изменение, лайки и удаление фото не сохраняются. Таблицы фото и лайков в миграциях не означают готовую реализацию. Сохраняй моки до отдельной задачи на их замену.
- Учётные записи auth и API связаны по username; UUID различаются.
- Ошибки выполнения GraphQL могут возвращаться с HTTP 200 в `errors`, классификация — `extensions.classification`. Невалидный Bearer-токен отклоняется фильтром с HTTP 401 до GraphQL. Query требуют `read`, mutation — `write`; передаётся access token.
- Java-модель генерируется из GraphQL-схемы в `build/generated`; меняй исходную схему, а не сгенерированные классы.
- При удалении пользователя сначала очищаются его связи в `friendship`: каскадного удаления внешними ключами нет.
