# rfr-auth

Подробности OAuth, форм и настроек — в [README.md](README.md).

- Регистрация создаёт пользователя только в `rangiffler-auth`; профиль API появляется при первом `Query.user`. UUID этих записей независимы.
- `POST /register` требует CSRF-токен из той же сессии после `GET /register`. Успех — HTTP 201; валидация и занятый username — HTTP 400.
- `GET /login` без сохранённого OAuth-запроса перенаправляет на фронтенд. Проверяй вход через кнопку Login, которая начинает OAuth-переход.
- Ключ RSA, OAuth-авторизации и сессии находятся в памяти. Перезапуск требует повторного входа; публичный клиент не получает refresh token.
- Текст ошибки входа локализуется. Если тест ожидает `Bad credentials`, задай английскую локаль запроса, чтобы результат не зависел от языка ОС.
