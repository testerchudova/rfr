# rfr-gql-client

Команды и устройство фронтенда — в [README.md](README.md).

- Фронтенд запускается отдельно от Gradle. Порт 3001 должен совпадать с OAuth redirect URI в auth.
- Ответ мутации обновляет кэш Apollo, а snackbar сообщает о завершении запроса. Это не подтверждает сохранение в БД: после ожидания ответа проверь значение новым сетевым чтением, например после reload, для реально реализованной операции.
- Фото, лайки, лента и статистика на сервере — моки. Успешное сообщение об операции с фото не означает, что данные переживут повторное чтение.
- Новые GraphQL-операции оформляй отдельными хуками с постоянным `operationName`. В API отправляется access token; id token используется в OIDC logout.
- Используй существующие компоненты MUI вместо параллельной собственной реализации.
